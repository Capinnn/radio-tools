# Broadcast engine

This directory runs a continuous MP3 stream from playlists generated by the
repository's `playlistgen` command. Liquidsoap reads the ordered M3U, applies
ReplayGain and a four-second crossfade, and sends `/radio.mp3` to Icecast.
Silence with a `Rotation unavailable` title keeps the mount alive when the
playlist is absent or empty.

## First setup

The checked-in Icecast file is a valid XML template. `bin/start.sh` fills its
placeholders from the environment and writes a mode-0600 runtime copy under
`logs/`; no credential is stored in Git.

```bash
cd /home/calebpineda/radio-tools/liquidsoap
cp config/secrets.env.example config/secrets.env
chmod 600 config/secrets.env
# Edit config/secrets.env and replace the source password placeholder.
```

`config/secrets.env` is optional and gitignored. Instead of creating it, export
`ICECAST_SOURCE_PASSWORD` before starting. `ICECAST_ADMIN_PASSWORD` and
`ICECAST_RELAY_PASSWORD` are optional and otherwise use the source password.
Passwords must be at least 12 characters and use URL-safe punctuation; this
keeps environment substitution from producing malformed XML.

Edit `config/rotation.json` to match the category names in the music library.
It follows [`broadcast/formats.md`](../broadcast/formats.md). Then generate the
first hour:

```bash
bin/gen-playlist.sh --source /absolute/path/to/music
# Or use a broadcast-format index:
bin/gen-playlist.sh --library /absolute/path/to/library.json
```

The wrapper activates `/home/calebpineda/radio-tools/.venv`, calls the installed
`playlistgen` entry point, validates the JSON sidecar against the M3U, publishes
both files atomically, and touches `data/playlist.trigger`. A failed generation
leaves the currently playing hour untouched.

## Daily operation

Start rotation mode, inspect status, and stop the chain with:

```bash
bin/start.sh
curl http://127.0.0.1:8000/status-json.xsl
bin/stop.sh
```

For live assist, use:

```bash
bin/start.sh --live
```

`scripts/live.liq` enables the default PulseAudio input. When that input is
ready it takes priority with a one-second transition, while a dummy output keeps
the rotation clock advancing underneath. The adjacent commented line shows the
JACK alternative. Stop the PulseAudio source (or disconnect JACK) to return to
the current point in rotation.

For an always-running playlist generator:

```bash
bin/gen-playlist.sh --source /absolute/path/to/music --loop
```

It generates immediately, then sleeps to the next local hour boundary. For
cron, run the one-shot command at minute zero instead:

```cron
0 * * * * /home/calebpineda/radio-tools/liquidsoap/bin/gen-playlist.sh --source /absolute/path/to/music >> /home/calebpineda/radio-tools/liquidsoap/logs/playlistgen.log 2>&1
```

Useful generation options are `--rotation`, `--daypart`, `--seed`, `--slot`,
`--output`, `--trigger`, and `--dry-run`. Equivalent defaults can be supplied as
`RADIO_MUSIC_DIR`, `RADIO_LIBRARY`, `RADIO_ROTATION`, `RADIO_PLAYLIST`, and
`RADIO_PLAYLIST_TRIGGER`.

Logs and PID files live in `logs/`. The generated playlist and sidecar live in
`data/`. Both runtime directories are ignored except for their `.gitkeep`
files. Start and stop refuse to run as root unless `--force-root` is explicit.
